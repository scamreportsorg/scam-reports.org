# Contributor Covenant Code of Conduct

## Our pledge

Everyone should be able to work on Scam-Reports.org without harassment, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience, education, socioeconomic status, nationality, appearance, race, caste, color, religion, or sexual identity and orientation.

Help keep the project welcoming and safe.

## Expected conduct

Give useful feedback, respect different views, own mistakes, and take other people's privacy seriously.

Harassment, threats, sexualized attention, trolling, insults, publishing private information, doxxing, brigading, false accusations, retaliation, and using project spaces to target somebody are not accepted. Neither is weaponizing the report system.

This repository is for building the software. Reports, evidence, appeals, and personal disputes belong in the website flows, not issues, pull requests, discussions, or commit messages.

## Scope and enforcement

This Code applies in project spaces and whenever somebody officially represents the project. Website reports and moderation have their own rules.

Maintainers may edit or remove material that breaks this Code. When it is safe and useful, they will explain the decision. The response depends on harm and repetition and may be a correction, warning, temporary restriction, or removal. Threats, doxxing, severe harassment, and deliberate privacy breaches may result in immediate removal.

## Reporting a conduct problem

Email [scam.reports.org@gmail.com](mailto:scam.reports.org@gmail.com). Do not include scam evidence or unrelated personal information.

Security vulnerabilities go through [SECURITY.md](SECURITY.md). Disputes about a website report go through the website appeal process.

Maintainers will protect the reporter's privacy as far as practical. Bad-faith complaints, retaliation, and deliberately exposing a reporter's identity also break this Code.
